Entry for the [make.fun competition](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee): one pickup line, at most 200 characters, spoken by a vending machine to a passing human.

## Run

```sh
node main.ts
```

It writes one line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).

## The line

> You're the only coin I never want to give back as change.

Only a machine returns change — so the flirt is in the machine's own world: coins, exact change, the one thing it keeps instead of handing back.
